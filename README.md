NumPy Analyzer

📌 Project Description

NumPy Analyzer is a menu-driven Python application that uses the NumPy library to perform various operations on numerical arrays. It allows users to create 1D, 2D, and 3D arrays and perform mathematical, statistical, and data manipulation operations easily.

🎯 Features

- Array Creation: Create 1D, 2D, and 3D NumPy arrays.
- Indexing and Slicing: Access individual elements and extract parts of arrays.
- Mathematical Operations: Perform addition, subtraction, multiplication, and division on arrays.
- Combine and Split Arrays: Combine arrays using vertical stacking and split 2D arrays into smaller arrays.
- Search Operations: Search for specific values in an array.
- Sorting: Sort array elements.
- Filtering: Filter values using greater than, less than, and equal to conditions.
- Statistical Operations: Calculate sum, mean, median, standard deviation, and variance.
- Input Validation: Handle invalid inputs and prevent division by zero.
- Menu-Driven Interface: Navigate through different operations using a simple menu.

⚙️ Installation

Step 1: Install Python

Download and install Python 3.x if it is not already installed.

Step 2: Install NumPy

Open your terminal or command prompt and run:

pip install numpy

Step 3: Download or Clone the Repository

Clone the repository using:

git clone <your-repository-url>

Alternatively, download the project files to your computer.

Step 4: Run the Program

Open the project folder in your terminal and execute:

python main.py

Replace "main.py" with your actual Python filename if it is different.

🚀 How to Use

1. Run the Python program.
2. Create a NumPy array by selecting the desired dimension.
3. Choose an operation from the main menu.
4. Enter the required values when prompted.
5. View the result displayed on the screen.
6. Continue performing operations or select the Exit option to close the program.

📊 Available Operations

Option| Operation| Description
1| Create Array| Create a 1D, 2D, or 3D array
2| Mathematical Operations| Perform arithmetic operations on arrays
3| Combine or Split| Combine arrays or split a 2D array
4| Search, Sort, or Filter| Search values, sort elements, or filter data
5| Aggregates and Statistics| Calculate statistical values
6| Exit| Close the application
